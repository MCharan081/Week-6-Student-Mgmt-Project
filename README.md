# Student Management System

## Project Description
The Student Management System is a Python-based application that helps users manage student records easily.

It allows users to add, view, search, update, and delete student information. The application stores student records in a JSON file so that data is saved even after closing the program.

## Features
- Add new student records
- View all student records
- Search students using Student ID
- Update student details
- Delete student records
- Display student statistics
- Automatically save data in a JSON file
- Simple menu-driven interface

## Installation / Setup

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python main.py
```

## How to Run the Project

1. Start the application using `python main.py`.
2. Select an option from the main menu.
3. Add student details.
4. View, search, update, or delete student records.
5. View student statistics.
6. Select Exit to close the application.
